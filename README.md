# Cybersecurity Projects Portfolio

Hands-on cybersecurity labs demonstrating SOC workflows, endpoint security analysis, incident response, and threat detection using industry-standard tools and frameworks.

---

## Labs Include

- Endpoint security analysis and malware detection  
- Incident response lifecycle (identify, contain, eradicate)  
- Log analysis and alert triage (SOC workflows)  
- Network defense and threat investigation  

---

## Folder Summaries

### Cloud Projects
Hands-on cloud labs building knowledge in cloud infrastructure, IAM, networking, and cloud security controls.  
**Skills Practiced:** Configuration, troubleshooting, technical documentation.  

### Endpoint Security
Analyze endpoint alerts, investigate suspicious processes, and document remediation steps.  
**Tools:** Windows Defender, Event Viewer, PowerShell  
**Skills Practiced:** Incident response, log analysis, threat detection  

### Incident Response
Documenting hands-on exercises focused on identifying, analyzing, and responding to security incidents.  
**Scenarios:** Phishing emails, malware containment, suspicious account activity  
**Skills Practiced:** Incident lifecycle, evidence collection, containment, documentation  

### Network Defense
Labs focused on network security concepts, traffic analysis, and defensive techniques.  
**Tools:** Wireshark, network logs, CLI networking tools  
**Skills Practiced:** Traffic monitoring, threat detection, firewall/IDS concepts  

### Threat Analysis
Analyze potential threats using indicators, behavior patterns, and threat intelligence frameworks.  
**Skills Practiced:** IOC analysis, MITRE ATT&CK mapping, analytical thinking  

### Vulnerability Management
Hands-on labs for identifying, analyzing, prioritizing, and remediating vulnerabilities.  
**Tools/Frameworks:** Vulnerability scanners, CVE/NVD references  
**Skills Practiced:** Risk-based vulnerability management, remediation planning
